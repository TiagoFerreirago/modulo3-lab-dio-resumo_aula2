# modulo3-lab-dio-resumo_aula2
Este repositório contem as lições aprendidas durante o desenvolvimento do lab-DIO-AZURE

## Mineração de conhecimento

- Encontra insights em escala, como palavras e frases-chave.
- Azure Cognitive Search – plataforma de mineração de conhecimento da Azure

## Soluções de pesquisa cognitiva da Azure

- Azure Blob Storage Containers: reconhece vídeos, imagens e documentos.

- Data Lake Storage Gen2: armazena dados.

- Azure Table Storage

## Enriquecimento e índice de IA

- Permite uma compreensão mais profunda.

- A indexação torna o conteúdo pesquisável.

## Enriquecimento de IA

- Torna o conteúdo mais útil para fins de pesquisa.

- Ocorre por meio de texto, dados, vídeos e documentos.

- É criado por conjuntos de habilidades, como: reconhecer entidades no texto, traduzir texto e avaliar sentimentos.

## Criar uma Storage Account

![conta_armazenamento](https://github.com/TiagoFerreirago/modulo3-lab-dio-resumo_aula2/blob/main/images/azure-conta-armazenamento.png)

![criar_conta_arm](https://github.com/TiagoFerreirago/modulo3-lab-dio-resumo_aula2/blob/main/images/azure-conta-armazenamento2.png)_

- Definir assinatura, grupo de recursos, nome, região, tipo de performance e a redundância.

- As configurações não personalizadas receberão as configurações padrão.

- Selecionar “Revisar + Criar” e, em seguida, selecionar “Criar”.

- Armazena diferentes tipos de estruturas e dados.

![armazenamento_config](https://github.com/TiagoFerreirago/modulo3-lab-dio-resumo_aula2/blob/main/images/azure-conta-armazenamento_config.png)

- Para ter acesso anônimo, é preciso habilitar em “Settings” (configurações).

## Criar recurso de IA com Azure AI Services

![services_IA](https://github.com/TiagoFerreirago/modulo3-lab-dio-resumo_aula2/blob/main/images/azure-ai-servi%C3%A7os.png)

## Criar um Azure Cognitive Search
